Introduction back to ToC

This ontology is part of the catalog of ontologies that is being developed in the context of the Data Space for Smart Urban Infrastructures (EDINT). It was also identified as a relevant ontology for the representation of data managed by local entities in the guide Datos abiertos FEMP 2019: 40 conjuntos de datos a publicar por las Entidades Locales, as also described in the corresponding data.gob.es note, and therefore included in the Github repository supporting the initiative, which will be deprecated once this repository is launched. An amplified version of the guide can be found in DATOS ABIERTOS 80 CONJUNTOS DE DATOS
